# Caminode

**Caminode is the personal software portfolio and product studio of Amir Thapa Magar.**

It presents a growing collection of independent applications, AI powered tools, and full stack products built for real users. The site is intentionally simple: one fast static page, clear product cards, direct links, and a focused identity around thoughtful software.

## Studio Direction

Caminode is built around practical software craft.

1. Full stack web applications that move from idea to usable product.
2. AI integration solutions that turn language models, automation, and intelligent workflows into real features.
3. Independent tools for learning, productivity, documentation, focus, and technical workflows.
4. Clean portfolio presentation for public product launches, experiments, and ongoing applications.

## Latest Release

### DeutschTrack

DeutschTrack is the latest AI integrated application from Caminode.

It is a free German learning application designed for learners preparing for Ausbildung. The product combines CEFR learning, Ausbildung selection, adaptive career vocabulary, interview preparation, text to speech practice, and Gemini powered AI dialogue generation.

Website: [www.deutschtrack.com](https://www.deutschtrack.com)

Google Play: [DeutschTrack on Google Play](https://play.google.com/store/apps/details?id=com.caminode.deutschtrack.deutschtrack)

Key ideas:

1. Learners choose an Ausbildung path.
2. The app adapts vocabulary and interview practice around that career goal.
3. Gemini powered dialogues help learners rehearse realistic German situations.
4. Text to speech practice helps learners hear and repeat useful German phrases.
5. The product keeps learning approachable through progress, streaks, and bite sized lessons.

## Technical Shape

This portfolio is a static website made with plain HTML and Tailwind through CDN.

It is designed to be easy to host, easy to maintain, and fast to update when a new application is released.

Core files:

1. `index.html` contains the complete portfolio page.
2. `assets/deutschtrack-logo.png` contains the DeutschTrack app logo used in the new project card.
3. `assets/deutschtrack-social-preview.svg` contains the DeutschTrack showcase preview used in the new project card.
4. `CNAME` points the GitHub Pages deployment to `caminode.com`.
5. `LICENSE` contains the MIT license.
